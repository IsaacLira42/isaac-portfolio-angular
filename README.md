## 📌 Sobre o projeto

Este projeto é meu portfólio pessoal, desenvolvido para apresentar minha trajetória,
projetos, tecnologias estudadas e formas de contato.

A aplicação foi construída utilizando Angular com uma arquitetura baseada em
componentes reutilizáveis, separação de responsabilidades e layout responsivo.

- Header
- Hero
- Sobre

- Contato
- Modal
- Footer

Cada componente possui sua própria estrutura de HTML e lógica,
facilitando manutenção e evolução do projeto.

## 🚀 Executando localmente

Clone o repositório:

```bash
git clone https://github.com/IsaacLira42/isaac-portfolio-angular.git
```

Entre no diretório:

```bash
cd isaac-portfolio-angular
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
ng serve
```

Acesse:

```
http://localhost:4200
```
