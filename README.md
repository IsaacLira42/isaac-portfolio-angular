## 🚀 Rodando o projeto

Clone o repositório:

```bash
git clone https://github.com/IsaacLira42/isaac-portfolio-angular.git
```

Instale as dependências:

```bash
npm install
```

Execute:

```bash
ng serve
```

Acesse:

```
http://localhost:4200
```
